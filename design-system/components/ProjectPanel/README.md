# ProjectPanel

A full-bleed project section in its own material: scene, name, lede, measured stats, feature tags, actions and a floating code sample.

- Props: `project` `engine | brain | shader`, `align` `left | right` (alternate on the home page), `code` (`false` hides the sample), `still`.
- Content comes from `PROJECTS` in `bundle.js` — keep stats measured and code taken from the repository.
- Under 960px the scene sits above the copy and the code card stacks below.
