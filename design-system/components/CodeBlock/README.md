# CodeBlock

A chamfered code card with file name, language, copy button, line numbers and highlighted lines.

- Props: `code` (string), `lang` `rust | bash | json | glsl`, `title` (file name), `highlight` (1-based line numbers), `lineNumbers` (default on), `floating` (glass card for use over scenes).
- Keywords are copper in every theme; highlighted lines take the theme's `accent-soft`.
- In bash, prefix commands with `$ `; Copy strips it.
