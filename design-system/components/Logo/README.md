# Logo

The GoingRusting mark — the angular copper G with its cream cap — optionally with the two-tone wordmark.

- Props: `size` (px, default 32), `wordmark` (adds "Going" in `ink` + "Rusting" in `copper`), `href`.
- Geometry is copied from `assets/Logos/GoingRusting.svg`; never redraw, rotate, outline or recolour it.
- Use on `surface-000` or `surface-100`. Minimum size 20px. Clear space: half the mark's width on every side.
