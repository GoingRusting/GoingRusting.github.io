# GoingRusting website

The site for the [GoingRusting](https://github.com/GoingRusting) organization: a welcome page for every project, plus docs and tutorials for each in its own theme.

Astro (static output), Shiki for code, Pagefind for search. The look comes from `design-system/` — read `CLAUDE.md` before changing UI.

```sh
npm install
npm run dev            # http://localhost:4321
npm run build          # dist/ + Pagefind index (search only works on the build)
npm run preview
npm run sync-content   # re-pull docs/tutorials from the repos' main branches into src/content/pages
```

Docs and tutorials in `src/content/pages/` are generated by `scripts/sync-content.mjs`; edit them in the project repos, then re-sync. The page list lives in the script's `MANIFEST`.

Deploys to GitHub Pages on every push to `main` (`.github/workflows/deploy.yml`). Set **Settings → Pages → Source** to "GitHub Actions". The base path is picked up automatically.
